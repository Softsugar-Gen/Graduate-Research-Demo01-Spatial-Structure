## 研究背景・目的

現在、私は先延ばし行動が創造性に与える影響について研究しています。

一般的に、先延ばしは悪いことだと思われがちですが、必ずしも悪い影響だけではないと考えています。

例えば、作業を一度後回しにすることで、考える時間が増えたり、新しいアイデアが生まれたりすることもあると思います。

そこで、インタラクティブなゲームを制作し、先延ばしと創造性の関係を探りながら、ゲーム内でのプレイヤーの状態変化を分かりやすく表現したいと考えています。

このプロジェクトは、そのゲームの一部となる空間編集デモです。

プレイヤーは部屋の大きさを変えたり、家具を配置したり、照明を調整したりできます。

まずは自由に変更できる3D空間を作り、今後はゲーム内の状態データと空間の変化を結びつけていきたいと考えています。

## 技術的な実装

**1. 部屋のサイズ調整システム**

<ins>**Unity UI**</ins>のSliderを使って、部屋の幅と奥行きを調整できるようにしました。

`OnValueChanged`イベントを使い、スライダーの値が変わったときにC#のメソッドを呼び出しています。

そして、`Transform.localScale`を使って、床と土台のサイズを変更しています。

また、床と土台のサイズの差を維持することで、部屋のサイズを変えても全体の形が崩れないようにしています。

**2. 壁の自動調整システム**

部屋のサイズを変更したときに、壁が床の端に合うようにするため、スライダーの値の差を利用しています。

プログラムでは、スライダーの前回の値と現在の値を比較し、部屋がどれくらい大きくなったか、小さくなったかを計算しています。

その結果を使い、壁の`localPosition`と`localScale`を変更しています。

また、スライダーの値が変わったときだけ処理するため、`Update()`で毎フレーム確認する必要はありません。

**3. カメラの回転中心**

プレイヤーが部屋を見やすくするため、空のGameObjectをカメラの回転中心として使っています。

ゲーム開始時に`GameObject.Find()`で床と回転中心を取得し、`Transform.position`を使って回転中心を床の中央に移動させています。

今後は、この仕組みを利用してカメラの回転や視点の切り替え、リセット機能を制作する予定です。
